# Microcontroller Experiments: Hotter or Colder Than Median Temp

## About

An Arduino project utilizing a temperature sensor where an RGB LED glows bluer the colder the current temp is from the median of all temps ever recorded on the microcontroller, and redder the warmer it is from the median.

## Components

1. Arduino UNO
2. Breadboard
3. RGB LED
4. Temperature sensor
5. 2 x 220ohm resistors
6. 8 x jumper wires
